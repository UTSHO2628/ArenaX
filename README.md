# ArenaX
Robotics & Hackathon Tournament Manager.
Overview
ArenaX is a lightweight and powerful tournament management system designed for robotics competitions and hackathons. It helps organizers streamline event setup, manage participants, track scores, and generate results in real time.

Features-
Tournament Creation: Easily set up robotics or hackathon events with custom rules.
Team & Participant Management: Register, edit, and organize teams with detailed profiles.
Arena Control: Manage match schedules, arena assignments, and competition flow.
Scoring System: Real‑time score tracking with customizable scoring logic.

Leaderboard: Auto‑generated rankings and statistics.
Export & Reports: Generate event summaries, score sheets, and analytics.

Tech Stack-
Frontend: React / Next.js
Backend: Node.js / Express
Database: MongoDB / PostgreSQL

⚡ Usage
Create a new tournament from the dashboard.
Add teams and participants.
Configure scoring rules and arena settings.
Start matches and track scores in real time.
View leaderboard and export results.
